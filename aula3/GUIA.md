# Aula 3 - CREATE, INSERT, UPDATE e DELETE

## Objetivo

Entender como criar uma tabela e fazer as quatro operações básicas de dados.

## Ordem segura da aula

1. `CREATE TABLE` cria a estrutura.
2. `INSERT` adiciona registros.
3. `UPDATE` altera registros com `WHERE`.
4. `DELETE` remove registros com `WHERE`.

## Aviso importante

Sempre faça um `SELECT` antes e depois de `UPDATE` ou `DELETE`. O banco de treino usa uma tabela pequena para que todos possam acompanhar.
