# Trilha gratuita para os exercícios avançados

Esta trilha é opcional. Ela prepara o aluno para os cenários extras de Power BI, consultas mais longas e a introdução ao Databricks. Não é necessário concluir tudo para acompanhar as dez aulas da oficina.

## 1. Consolidar T-SQL

**Microsoft Learn - Consultar e modificar dados com Transact-SQL**  
Roteiro gratuito, em português, com aproximadamente 5h45. Revisa `SELECT`, filtros, ordenação, `JOINs` e manipulação de dados.

Link: <https://learn.microsoft.com/pt-br/training/paths/get-started-querying-with-transact-sql/>

Use esta etapa antes de tentar os exercícios avançados de SQL.

## 2. Praticar consultas com correção automática

**Oracle Dev Gym - Databases for Developers**  
Cursos e exercícios gratuitos no navegador, com aulas de fundamentos, próximo nível e performance.

Link: <https://devgym.oracle.com/pls/apex/dg/competition/sql>

O banco usado é Oracle, então alguns detalhes de sintaxe podem mudar. O raciocínio de filtros, agregações e relacionamentos continua útil.

## 3. Preparar dados no Power BI

**Microsoft Learn - Preparar dados para análise com o Power BI**  
Roteiro gratuito, em português, com aproximadamente 4h33. Ensina conexão com fontes relacionais, Power Query, limpeza e preparação de dados.

Link: <https://learn.microsoft.com/pt-br/training/paths/prepare-data-power-bi/>

Para a oficina, o aluno pode praticar no Power BI Desktop e salvar o relatório apenas no próprio workspace.

## 4. Conhecer modelagem e visuais

**Microsoft Learn - Treinamento para analistas de dados**  
Reúne os roteiros gratuitos de introdução, preparação e modelagem no Power BI.

Link: <https://learn.microsoft.com/pt-br/training/career-paths/data-analyst>

Conclua primeiro a introdução e a preparação. A modelagem é recomendada para quem quiser avançar nos PDFs de cenários da aula 9.

## 5. Introdução ao Databricks

**Databricks Community - Learning Paths**  
A comunidade oferece o curso gratuito Databricks Fundamentals e caminhos de aprendizagem para praticar na Free Edition.

Link: <https://community.databricks.com/t5/learning-paths/ct-p/databricks-learning-paths>

Também existem sessões gratuitas com instrutor, inclusive com filtro de idioma e região:

<https://community.databricks.com/t5/free-instructor-led-training/ct-p/free-instructor-led-training>

## Ordem recomendada

1. Microsoft Learn T-SQL.
2. Oracle Dev Gym - fundamentos e próximo nível.
3. Microsoft Learn Power BI.
4. Databricks Fundamentals.
5. Exercícios opcionais da pasta `aula9`.

## Resultado esperado

Ao concluir as três primeiras etapas, o aluno já deve conseguir:

- combinar tabelas com `JOIN`;
- usar agregações e agrupamentos;
- preparar uma consulta para importar no Power BI;
- limpar dados simples e criar um visual;
- entender a diferença entre uma consulta SQL local e uma célula SQL em um notebook.
