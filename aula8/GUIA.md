# Aula 8 - Introdução ao Databricks

## Objetivo

Conhecer workspace, notebook e célula SQL no Databricks.

## Atividade curta

O instrutor apresentará uma tabela de exemplo e executará:

```sql
SELECT *
FROM vendas
LIMIT 5;
```

Depois, cada aluno altera apenas o número do `LIMIT` e explica o resultado. Não haverá configuração de cluster nem conteúdo avançado de engenharia de dados.
