# Aula 7 - Projeto guiado

Cada grupo escolhe uma pergunta sobre a `EmpresaBrasil` e entrega a pergunta em linguagem simples, a consulta SQL e uma frase explicando o resultado.

Sugestões: clientes que fizeram pedidos; três produtos mais caros; clientes por estado; funcionário com mais pedidos.

Use somente `SELECT`, filtros, agregações e `INNER JOIN` ou `LEFT JOIN`. Não é necessário criar tabelas novas.
